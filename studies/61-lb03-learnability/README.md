# Pass 61: LB03-LEARNABILITY

[Study index](../README.md) · [Research map](../../RESEARCH_MAP.md)

Test whether smaller learning copies can actually learn, not merely keep an already-mastered skill.

Retained ledger status: **COMPLETE_BOUNDED_LEARNING_STOCHASTIC_SCREEN_MET_WITH_LIMITS**

**Source-reported result (readable summary):** All 24 learning paths completed 512 main updates each. All modes learned in EARLY, and all obtained 32/32 tested cue answers in NEW, including two reversals. Old-task retention passed 3/4, 2/4 and 3/4 parents for M32, FP16 nearest and FP16 stochastic masters respectively. Stochastic rounding met the frozen cohort screen separately in both regimes, but only two identical parents passed both. Named learning arrays were 19.45% smaller; the broader union saving was about 1.41%, with stochastic training 8.9-11.7% slower. Retained audit/replay results support the bounded comparison; sigmoid overflow warnings and large gate inputs remain explicit numerical robustness limits. These are historical measurements, not fresh execution during repository preparation.

Evidence description in source: Executed mixed-precision full-parameter learning and retained competence comparison; source archive/lineage audit; internal reproduction, no external replication.

This page is a navigation/reconciliation aid. It does not rewrite historical protocols or certify a completed experiment.

**Qualification limit:** mixed precision only. Stochastic rounding passed the frozen cohort screen separately in EARLY/NEW; only two identical parents passed both. Retention remained mixed. Named-array saving was 19.45%, broader union about 1.41%, with slower measured training. Sigmoid overflow warnings and large gate inputs remain a robustness limit. No independent external replication or whole-system qualification.
