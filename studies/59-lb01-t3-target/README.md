# Pass 59: LB01-T3-TARGET

[Study index](../README.md) · [Research map](../../RESEARCH_MAP.md)

Try switching four-setting weights to three settings immediately or gradually; see whether the small model still finishes its checklists correctly.

Retained ledger status: **COMPLETE_BOUNDED_COMPARISON_NO_TERNARY_WORKING_POINT_Q2_RETAINED**

**Source-reported result (readable summary):** Four prepared Q2_M32 parents were compared using Q2 control, immediate ternary conversion and a gradual ternary ramp. Neither ternary path met its whole-task target (0/4 each). Q2 passed the nominal criterion on 4/4 parents but the stricter long-stress criterion on only 2/4. The ramp also changed pure-ternary exposure and learning-rate timing, so this does not disprove every gradual quantization strategy or three-valued codebook.

Evidence description in source: Executed model-quantization comparison with fixed same-task preparation; no new cue, repair, optimized training state or BitNet Transformer replication.
