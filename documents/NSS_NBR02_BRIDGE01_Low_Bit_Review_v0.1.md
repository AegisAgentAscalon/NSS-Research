## Keep learning approaches distinct

- **Quantized-base adapters (QLoRA):** freeze the quantized base and train added adapters. Count adapter and optimizer state. This tests task-specific adaptation, not full-base updates.
- **QAT or quantization-aware reconstruction:** simulate/apply quantized weights while training full-precision masters and/or quantization scales, or reconstruct quantized blocks. Count those masters, gradients, activations, and workspaces. Fake quantization is not native low-bit inference.
- **Reduced-precision full-parameter learning:** declare precision of forward weights, persistent trainable parameters, gradients, updates and accumulators separately. BitNet's ternary forward weights motivate a candidate; they do not imply an entirely ternary training system. Count any higher-precision latent/master copy. Learning directly in low-bit persistent parameter state without that copy is a separate, unproven NSS hypothesis.
- **Quantized optimizer states:** an orthogonal option. Four-bit moments reduce optimizer-state width, not weight precision.

The checked primary papers support these distinctions: [BitNet b1.58](https://arxiv.org/abs/2402.17764), [QLoRA](https://arxiv.org/abs/2305.14314), [4-bit optimizer states](https://arxiv.org/abs/2309.01507), and [EfficientQAT](https://arxiv.org/abs/2407.11062). Their results are not NSS results.

For any training candidate, account for preparation/calibration, parameter and master weights, gradients, optimizer moments/residuals, activations, temporary workspaces, recurrent state, KV cache if applicable, exact records/journals/snapshots, framework allocations, and runtime. Compare identical source, data, task, update budget, initialization, and seed schedule; separate development and evaluation inputs. Report tensor categories and process peak, not just nominal bitwidth.

My first training hypothesis is that optimizer-state compression can save persistent learning memory while wider parameters/update accumulation preserve small useful updates. Compare a declared full-precision optimizer reference with its compressed-state counterpart on a controlled new correction or skill plus old-task continuation. Both must actually acquire the new behavior; retaining old behavior by failing to learn is not success. Fix the learning fixture and cost budget before confirmation. This can be planned alongside the inference probe, without requiring every inference condition to pass first. Native savings and useful language adaptation remain separate scale questions.
