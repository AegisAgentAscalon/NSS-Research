# BRIDGE01 v0.1 evidence review

This is a read-only review of the supplied prototype and review ZIPs. I inspected archive metadata, selected documentation, source modules, and retained JSON records. I did not execute package code or tests, run model inference or training, or deserialize checkpoint weights. Machine checks and retained metadata are in [AUDIT.json](AUDIT.json); selected text is in [SELECTED_EVIDENCE.txt](SELECTED_EVIDENCE.txt).

## What is implemented

The bridge joins three deliberately small parts. A deterministic scripted adapter emits the six-field proposal JSON; it is not a language model. A frozen GRU advisor reads trusted, typed journal events and suggests the next step. An exact eight-step task ledger, approval check, and local SQLite journal validate every proposal and record simulated effects. Owner/task routing, event-to-token mapping, task state, and permissions are ordinary software. The neural model receives no English, creates no approval or receipts, and cannot change the ledger. Its advice can influence a proposal in recurrent mode, but the exact gate controls acceptance. Shadow mode records its advice while using the rule result.

The learned component is a real inherited checklist network, not a stub: its source loads six trained tensors and performs GRU and linear-head arithmetic. The archived `.npz` exports have float32 array headers with shapes 192×26, 192×64, 192, 192, 9×64, and 9. Runtime code casts weights and recurrent state to float64 and marks the weights read-only. The package also retains one `.pt` Torch-format checkpoint beside each export. Their member paths are `models/parent_4101` through `models/parent_4104`, each with `.npz` and `.pt` files, inside `NSS_NBR02_BRIDGE01_Prototype_v0.1.zip`. The package describes these as the original CYCLE01-A parents and lossless exports; this review checked container and array metadata but did not load either format to independently compare tensor values.

There is no low-bit implementation in the reviewed inference source: no quantized storage, fake-quant path, packed low-bit tensor, or native low-bit kernel. Existing weights are float32 in the export and execute as float64; no optimizer application or new training is recorded. The saved checkpoints are useful small inference instruments, not evidence of low-bit arithmetic.

## What the retained results support

The retained `results/main/SUMMARY.json` contains 216 authored sessions: 24 rule, 96 shadow, and 96 recurrent; all are marked complete. It records 2,072 correct neural suggestions in each neural mode (4,144 total), with zero false-DONE predictions. `audit/AUDIT.json` records 216 fresh-process replay matches, 4,144 event labels checked, 302,512 numerical scalars compared with PyTorch, zero differing argmax classes, and a maximum absolute difference of about 7.11e-15 at the declared tolerance. The preflight receipt records 41 checks passed, including a loopback HTTP test whose reply remained scripted. These are retained run claims read from the package, not fresh execution or replication in this review.

This demonstrates wiring and numerical agreement on a finite, authored checklist trace. It does not show a general learned orchestrator or an advantage over exact-rule coordination. The cases reuse behavior across naming variants; the dummy response follows the supplied suggestion; and a correct suggestion is the lowest unfinished item in a fixed eight-step workflow. The adapter does not generate or understand language. Tool effects and receipts are local simulations, not uploads or arbitrary external actions. No live LLM, transformer, native Windows runner, low-bit arithmetic, or training ran.

## Integrity and useful baseline

Both supplied ZIPs pass CRC checks. Every manifest member, size, and SHA-256 matches; both manifest sidecars match their manifest bytes, and no unlisted or missing members or suspicious absolute/traversal paths were found. The standalone architecture/low-bit DOCX is byte-identical to `docs/ARCHITECTURE_AND_REPORT.docx` in the prototype. No archive integrity defect was found.

For a future LB01 protocol, retain these exact source exports and event traces as a fixed reference, while adding an explicitly measured float32 inference reference because the current runtime is float64. Compare weight precision first with recurrent state held fixed, then state precision with weights fixed; define separately whether the candidate only stores packed values or actually executes low-bit arithmetic. Record scales, temporary/dequantized buffers, state bytes, and process memory. Keep the exact ledger and rule mode as controls, and judge raw neural suggestions as well as gated completion so the software guard cannot stand in for model quality. Later learning-memory work should evaluate full-parameter updates and count optimizer/master state; frozen-base adapters alone would not answer that question. Other research topics remain preserved as deferred work while low-bit inference and training take priority.
