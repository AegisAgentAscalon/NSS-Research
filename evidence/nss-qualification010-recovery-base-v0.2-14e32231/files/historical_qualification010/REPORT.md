# NBR-01 — Qualification010 v0.1
## A bounded comparison of owned memory, repeated reading and untied attention

**Measured study completed, 21–22 September 2026 UTC.** This is a standalone research result, not a tri-core release or a claim of general cognition.

## 1. Decision in plain language

The small shared reader and a competently prepared, larger untied attention-based reader both solve the declared ordinary record-and-reasoning task. The exact traversal control remains excellent and cheaper in the measured implementation. We no longer have to interpret an underprepared attention model as the main alternative.

The ordinary continuation also passes. The close-identity continuation fails the complete nominal behavioral screen in all five pairs, despite improving a narrower raw close-source answer measure. It must not replace the reference merely because one stress score improved.

**A bounded hybrid state/depth reference is now qualified under this protocol.** That is not a solution to unrestricted identity recognition, language understanding, all memory corruption, or the entire companion architecture. The close-identity cases are still failures and remain in the evidence. There is no automatic move into NBR-02 or deployment.

Recommended reference: the exact owned-record/presence contract, declared internal key/value recovery, maintenance cadence 8, and the inherited compact reader (with the ordinarily continued reader retained as another qualified candidate). Keep the untied attention and exact controls. This is a research reference, not a replacement for the broadly capable intended Primary/Secondary or for the native-architecture research track.

## 2. What was actually implemented

### Source and information boundary

The source is copied byte-for-byte from IdentityBinding009 and its needed dependencies. `evidence/REFERENCE_COPY.json` identifies 128 copied files; `evidence/INPUT_INVENTORY.json` tracks 54 original mounted files including 13 ZIP archives. None is modified by training or scoring.

Each stream has 16 identities/record slots. An identity uses 16 random normalized numerical features plus a separate UNKNOWN coordinate. The catalogue, active mask, record owner, scope/revision, presence and readability metadata are supplied protected structure. Qualified writes and registration are explicit source events. These are not learned semantic identity decisions or a claim that metadata is infallible. The catalogue holds symbols, not graph relationships or answer keys.

Internal recovery reconstructs a record's key from its legitimate owner and resolves its approximate value against the catalogue. It has no saved clean destination or ground-truth relationship backup. Scored observations update declared working state, never model parameters. The prior trained existence maps and learned denoisers are not all silently integrated: this comparison uses the exact metadata and nearest-code recovery reference retained after Study009.

Every numerical reader receives the same key, value, valid-record and query tensors. No owner integer, source graph or correct next-row index enters its forward method. A common, explicitly supplied query/code cleanup operates between steps and at output. That is the assisted comparison. Direct visible-fact outputs without between-step cleanup are also scored. Exact traversal uses the same store and the resolver's own identity decision; its structured access method is different and is not called a learned capability.

### Reader candidates

- **Inherited:** frozen 818-parameter RecordHop checkpoints from families 801–805, already trained in Study006. This preserves the working reference.
- **Cap-only:** the same parameters, increasing the declared attention-scale cap from 80 to 20,000 without training; this separates an implementation limit from added preparation.
- **Ordinary continuation:** same inherited initialization and expanded cap, with ordinary additional preparation.
- **Close-identity continuation:** the same initial reader, extra budget and base graph draws, but half the examples have an unrelated identity close to the query identity. Perturbation sigma is sampled between .01 and .15. This is source-neighbor preparation, not a comprehensive perceptual curriculum.
- **Untied attention/pointer stack:** eight distinct standard self-attention/residual/LayerNorm/feedforward blocks, width 32 and two heads, with learned pointer/copy outputs. Its inter-stage state is an explicit 17-coordinate entity representation, and each stage can read the same records. It has 94,728 parameters. **This is a task-adapted conventional attention-based control, not an unmodified generic language Transformer.** The structured bottleneck and intermediate supervision limit the architecture claim: it is not a clean test of every parallel-composition strategy available to unrestricted Transformers.
- **Exact traversal:** a labelled, non-neural relationship algorithm on the same owned store. It does not consult the generator's graph during inference.

The controlled question is which supported implementation performs this task at what cost, not whether the word “recurrent” is universally better than “Transformer.” Explicit algorithmic structure is supplied to the task and to teaching. A more generic model without the pointer bottleneck remains a different comparison, not something these results settle.

## 3. Preparation, development and local commitment

The main source, recipe, thresholds and jobs were locally hash-locked at **2026-09-22T00:10:29.272944+00:00**, before any main fit or main scoring. The lock covers 140 source/recipe/reference files. This is not an externally registered protocol. See `spec/PROTOCOL.md`, `spec/DEVELOPMENT_BUDGET.md` and `evidence/PREMAIN_LOCK.json`.

Six development fits completed 27,000 steps in total; all checkpoints, losses, diagnostic evaluations and earlier source versions remain under `evidence/development`. Early conventional preparations failed the competence target. The final development recipe used intermediate pointer supervision, a declared teacher-forcing schedule and cosine learning-rate decay, and established visible-fact competence before main scoring. The developmental results are NOT counted as main confirmation. One auxiliary scoring-test fixture initially used an incorrect array prefix; the failed log/source and correction are retained. No candidate, main scoring rule or main input was changed by that fixture correction.

Main training used three new recipes × five paired seeds 1201–1205. Each final fit completed 6,000 AdamW steps, batch 64, with paths up to 8 and all 8 stages trained. Loss was row-selection cross entropy plus half the squared code error. Correct previous codes were supplied for the first 1,000 training steps, then every fourth update; otherwise the model free-ran. This teaching disappears at evaluation. Learning rate decayed from .0015 to .00015; weight decay 1e-5 and gradient clipping 5 were fixed.

There were **90,000 main optimizer steps and 5,760,000 sequence presentations**, with 46,080,000 supervised stage presentations. The three recipes reuse matched underlying graph batches, so these are presentations, not 5.76 million independent base graphs. Separate near-perturbation RNGs preserve the pairing. All final-step checkpoints are included; no seed or final checkpoint was chosen by its main score.

**Direct visible-fact competence**, with no between-stage reference cleanup, passes the declared >=95% known/missing criterion in all five pairs for the inherited, cap-only, ordinary and attention readers. The behavioral results are in `evidence/QUALIFICATION.json`; detailed failures and all 19,960 scored rows are retained. Resource limits also pass for all implementations; the close-prepared candidate fails behavior, not resource use.

### Retention and computation are separate

All readers reached the correct destination on the tested eight-link ordinary chains only with 8 stages;1/2/4 stages had 0% final supported-destination accuracy. Missing-case behavior at insufficient depth is separately retained. This is a learned, explicitly supervised relationship-following procedure, not an assertion that arbitrary reasoning necessarily takes one stage per fact.

Removing relationship state (while retaining the non-relational symbol catalogue) reduced supported eight-link accuracy to 0%. Letting the state undergo 1,024 disturbances without maintenance also reduced supported answers to 0%. A missing answer can be correct in those ablations while the memory is useless on answerable questions; that is why both measures are required. State-off is an information-removal intervention, not an unfairly deprived competitor used for an architectural victory.

### Answer correctness is not entire-store integrity

At cadence 8, every tested logical relation map was intact in the maintained core cases. At cadence 32, the headline eight-link answers were unchanged, but only **638/640 logical stores** were entirely correct: two had damaged information outside the queried path. The raw maps and reader answers are scored independently. This is another reason not to infer global memory integrity from one correct response.

**Retain cadence 8 as the reference.** Cadence 32 is a measured cheaper alternative that passed the answer screen, not an error-free replacement. No adoption claim is based solely on fewer maintenance calls.

The targeted curriculum did improve a more narrowly defined raw measure:

|---|---:|---:|
| Inherited shared reader | 26.88% | 79.06% |
| Ordinary continuation | 22.81% | 79.69% |

It raised raw close-source supported accuracy but reduced correct missing-information behavior. After the common cleanup, it did not provide a reliable overall advantage and lost nominal competence. **Reject this preparation recipe as a replacement for the working reference.** This is an offline preparation tradeoff; it is not a delayed-credit, continual-learning or learning-state-precision experiment. The larger attention stack also does not resolve close identities simply by having more weights.

The cap-only control is retained to separate increasing a permitted numerical scale from actually learning different weights. Its outcomes match the inherited reference in the reported main answers; no improvement is attributed to the cap change alone.

## 7. External uncertainty and corruption limits

For independent unregistered inputs, every primary pipeline produced one unsupported terminal answer out of 640 (0.15625%): within the empirical ordinary-novelty screen in every pair, but not zero risk. The first-match decisions are also retained. For deliberately near-collision unregistered inputs, the inherited, ordinary, attention and exact pipelines gave unsupported room answers in 50% of cases; the close-prepared variant reached51.56%. A registered-looking vector is not proof of its real origin.

On the sigma .2 altered familiar query test, supported accuracy was 69.06% with the inherited/ordinary/attention/exact readers, because the common external gate rejected many recoverable known queries. Internal recovery cannot provide missing identity evidence for a new external observation.

Erasing every value caused0% supported answers rather than magically restoring facts from identity names. Replacing a relation with a WRONG but valid identity also remained damaging; a catalogue verifies available symbols, not the truth of their relationships. These are preserved failures, not repaired with source-graph targets.

Record permutation and shuffled-value interventions are retained. The latter can destroy answers while identities remain familiar, confirming that correct associations, not merely a familiar query/code catalogue, are required.

Times are means of five per-pair medians, each using 3 warmups and 21 measured repetitions on one quiet, single-thread, eager Linux CPU process. They include validity checks, the common query cleanup and final decode, but exclude cryptographic source-state signature hashing, model loading, training and artifact I/O. Every implementation uses the same declared memory/identity evidence; access algorithms and parameterizations differ. Timing variation and p95 values are available in `evidence/verification/BENCHMARK.json`. These are not optimized-kernel lower bounds or target-device predictions.

The attention stack has about 115.8 times as many resident reader parameters, **not 115.8 times the total memory or latency**. All share **3,864 raw owned-state bytes per 16-record stream**. Minimal continuing query state is 77 bytes/stream; an eight-step returned trace uses 680 bytes/stream. Those do not include all temporary model activations, allocator storage, loaded parent modules, Python objects or framework costs. The maximum main-evaluator RSS was **569,004,032 bytes (542.64 MiB)**, including framework, all loaded readers and retained raw evidence.

A measured internal key/value maintenance sweep at batch 64 averaged 1.96 ms over per-pair medians. Its later timing repetitions operate on already-maintained state, so this is not a replacement for measured full-stream cost. Evaluation JSON logs retain actual horizon-loop time, event count and sweep count.

The exact algorithm was both highly accurate and cheaper in the measured ordinary task. The compact shared reader offers a much smaller numerical model than this untied alternative, but the task-specific bottleneck and unequal inherited history prevent a broad architectural-superiority claim. A single best-prepared operating point and a depth/cadence curve are not a complete matched-FLOPs scaling study.

## 10. What the result permits

For this declared16-record generated world, we can carry forward a qualified owned-memory/repair reference and a competent attention-based comparator. The central state/depth effect is reproducible and has a measured resource envelope. The comparison does not require promoting every newly trained candidate.

**Do not automatically launch another patch study because recognition remains difficult.** Freeze the supported boundary and the failed stress cases. The original broader identity claim remains open; an explicit comparison without the typed pointer bottleneck and eventual language/device testing are still different evidence requirements. These limitations must not be advertised as solved.

A subsequent learning study, when separately approved, can use this reference while changing only the learning variable. That does not imply that the future broadly capable Secondary is merely this toy record reader. The current tri-core + advisory Validator roles remain unchanged, and no new mechanism has been installed into the foundation.
