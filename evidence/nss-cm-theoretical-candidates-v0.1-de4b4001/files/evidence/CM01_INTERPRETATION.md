# CM-01 v0.2 interpretation

**CM-01 passes its declared bounded fixed-weight pilot rule.** It tests a public-journal reference workspace over 512 labeled records, not the separate Q010-P1 proposal, which remains unrun. A fresh retained-row cross-check confirmed 23,040 decision rows, 512 case IDs and the primary near reader's held-out close-identity rise from 88/200 (44%) with the original query to 142/200 (71%) with the workspace. All five held-out episode families meet the predeclared gain/control rule. The five model seeds reuse each episode family, so 200 reader/case results are not 200 independent episodes. The archive reports zero optimizer updates and unchanged Q010 exports (`REPORT.md`, `STATUS.json`, `protocol/PROTOCOL.json`).

The archive's noise breakdown makes the benefit conditional. In the low-noise close stratum (sigma 0.01), near-reader accuracy changes 71/100 to 70/100. In the high-noise close stratum (sigma 0.2), it changes 17/100 to 72/100. The manager can replace a degraded query with a canonical query retained from an observable selection/correction journal. Thus the result supports **public-reference-assisted query reconstruction** at this one learned read endpoint. It does not isolate a newly learned memory skill. The archive reports the public exact-lookup control at 40/40 on each of ordinary-known and close-identity held-out records with valid bindings, outperforming the learned hybrid on close records. A valid public reference can directly retrieve its observed payload without neural reading; the exact control deliberately has no fuzzy fallback (`source/manager.py`, `REPORT.md`).

The archive reports structured fields and `UTF8_BYTE_V1` serialization agreeing on all 7,680 main reader/case comparisons. That supports encoding parity for this deterministic interface, not native language-model token competence: the packet is 56 ASCII bytes/control symbols. It is also not total memory. Per case, the public K/V/valid arrays occupy 2,192 bytes, the resolver catalogue/symbol arrays another 1,232 bytes, and the query 68 bytes. Reported canonical JSON journal and materialized directory sizes are roughly 12–14 KB and 13–14 KB respectively, with a binding index and lookup traffic in addition. Neither state compression nor net memory saving follows from packet width. The 32-event persistence unit test checks controller software state, not learned continuity or recurrent residence (`ALWAYS_RESIDENT_ADDENDUM.md`).

The archive's negative table separates safe reference management from task correctness. Observably stale, deleted, foreign-scope or detectably wrong references trigger 500/500 reported management abstentions in the held-out primary near arm. Four hundred are known-answer tasks and therefore recall failures; 100 deleted-record UNKNOWN answers are correct. In the no-cue condition, all 100 wrong public bindings are reportedly accepted. The learned output contains expected content in 33/100, but that does not validate a wrong binding. The archive identifies 64 opposite-truth pairs with byte-identical public history, workspace and numerical input yet different origin answers. This is an information limit for deterministic processing at that interface, not a reason to tune a gate on hidden truth. The public exact control's perfect absent response is achieved by returning UNKNOWN without a usable reference, with zero recall on those unbound known cases (`REPORT.md`, `protocol/PROTOCOL.json`).

This is a PASS for its scoped question: a retained public reference can improve noisy query recall while preserving declared controls, and the package reports independent scoring plus exact local replay of the new study. It does not show always-on learned tokens, model-managed writes, long-horizon continuity, an integrated Primary/Secondary/Tertiary system, or product qualification. The archived role-change interpretation is a proposal, not active authority to alter the frozen NSS roles. The original Q010 training-trace and full optimizer/RNG gaps remain; CM-01 provides no training requalification.

The smallest next comparison is conditional **CM-02 continuity**: test delay, task switches and correction while comparing workspace-plus-archive operation with recurrent/task state disabled, alongside the existing public exact control. Keep observable information and costs aligned so any later recurrent contribution can be identified separately.
