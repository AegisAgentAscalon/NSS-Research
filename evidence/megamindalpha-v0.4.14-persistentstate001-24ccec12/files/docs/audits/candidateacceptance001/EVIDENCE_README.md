# Recorded evidence, not current authorization

RELEASE_GATES.json contains exact commands, times, execution environment and raw output
hashes from the clean-extracted source. Every listed log was checked against its digest.
The absolute temporary paths describe that run; they are not portable artifact grants.
CANDIDATE_*_HISTORICAL.json are exports of its actual accepted-then-revoked owner history.
They cannot be substituted for live journals/current permission checks or used to renew
release authorization. Reproduction creates fresh artifacts using the public demo.

The final delivered source differs from the full-tested tree only in finalized audit /
progress documentation and the resulting release manifest. Executable input equality
and final extracted checks are recorded in the external release-verification sidecar.
No claim is made that these local checks constitute independent scientific review.
