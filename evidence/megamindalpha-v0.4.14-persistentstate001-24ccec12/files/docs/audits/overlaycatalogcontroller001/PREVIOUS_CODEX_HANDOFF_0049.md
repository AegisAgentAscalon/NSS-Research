# Turning this reference implementation into a proper NSS implementation

The simulator is a behavioral reference and regression suite, not a disposable
mock-up to rewrite wholesale. A coding agent can implement richer backends behind
its public contracts while retaining observable behavior and recovery tests.

Start from this exact version/hash and read AGENTS, NEXT_STEPS, the packet and audit.
Run existing tests. Classify every claim as implemented, simulated, planned or
research. Never promote a diagram, HUMAN label, fixture evidence_ref, recorded PASS
or hash into actual authority. There is no complete 0.6 implementation in this
branch, and no neural result should be inferred from arithmetic demos.

Replace ONE bounded stub/backend at a time. First record baseline outputs/failure
modes, implement the versioned boundary, add backend-specific failure/cleanup tests,
then rerun all inherited contract/integration gates. A change in behavioral semantics
requires an explicit plan deviation; fewer code lines do not justify deleting gates.
Keep subsystem ownership, configuration/task identity, source-use checks, artifact
pinning, stage handoffs and no-double-action recovery intact.

Production gaps include real neural training/evaluation, actual device/backend
capabilities, resource/latency/energy measurements, concurrency/isolation, authenticated
human/Nexus permissions, trusted qualification/evidence issuance, protected evaluation
exposure, retention/erasure behavior, full recovery on real hardware and the separately
reviewed Aegis Runtime adaptation. Implementing them requires evidence in their actual
environments, not merely a larger number of passing simulator tests.

recurrent depth, native HSA/MSA and DARP) must be tested separately. Prefer a small
neural probe now rather than completing every imagined service before learning
whether the neural hypothesis works. Preserve high-precision diagnostic controls
without silently abandoning the native ternary target.

Deliver full source, exact tests/logs, unresolved limitations, a versioned archive,
checksum and a fresh-extracted-package verification. Do not ship secrets, private
conversations, run databases, caches or unreviewed downloaded model artifacts.
