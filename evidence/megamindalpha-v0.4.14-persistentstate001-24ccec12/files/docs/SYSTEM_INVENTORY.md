# Remaining systems — scope and counting policy / 0.4.14

There is no honest single count of "systems left" without specifying the finish
line. The parent Logic Atlas has 25 design flows; many are partial, and one build
can serve several flows. More test methods do not make a flow production-complete.

## Proposed finish line A: an integrated local Alpha demonstration

After NeuralProbe001, group the remaining SOFTWARE work into **six main build
areas plus an end-to-end acceptance pass**. These are proposed work packages, not
six guaranteed coding turns and not six remaining problems for the full NSS vision.

1. Qualification evidence: a first trusted-local NeuralProbe001 implementation now exists
   in QualificationEvidence002. Exact claims, prerequisites, source checks and revocation
   work; the separate CandidateEvidence001 adapter now connects real new-A2 evidence; authenticated roles,
   protected benchmarks and arbitrary source adapters remain absent.
2. Nexus permissions: LocalNexusPermissions002 implements exact, expiring/revocable,
   one-use trusted-local replay grants and receipt reconciliation. Authentication,
   delegation and production runtime permits remain absent. Catalogue release uses the separate manager policy below.
3. Overlay Generation Manager: a first local catalogue release implementation now exists.
   Exact family closure, separate release grant, staged artifacts, atomic current/archive/receipt,
   managed-stage barrier and fresh-approved rollback work; device serving remains absent.
4. Overlay catalogue/controller: implemented for exact reviewed fixture descriptors,
   declared cost/mode limits and one selected QAP; source-aware durable stage lifecycle
   connects to the generation owner. Learned routing/VRAM paging remain absent.
5. Context/retrieval: ContextRetrieval001 now builds byte-bounded, task-bound packets
   from exact task sources and permitted reviewed experience. It revalidates consumption,
   supports exact source slices, and returns explicit missing/overflow outcomes. It is
   an explicit-ID/lexical shortlist baseline, not general semantic/native HSA/MSA.
6. Bounded learner coordinator: implemented human-assisted immutable plans, local
   training approvals, snapshot coordination, one-attempt real A2 training, independent
   numerical replay and review-only proposals. No learned gap diagnosis or self-promotion.

Connected acceptance now covers task -> reviewed experience -> snapshot -> NEW A2
training -> exact evaluation -> independent local qualification -> fresh release approval
-> staged/atomic new-family adoption -> managed A2B/A2/CORE task -> approved rollback.
All six local-demo software areas and the fresh-candidate integration are represented.
This closes finish line A in its stated synthetic trusted-local scope; an independent
review and the separate real Runtime integration still remain.

## Finish line B: the full intended NSS

Additional evidence/work remains: a genuinely capable Core; learned routing and
internal evaluator; identity/continuity evaluation; autonomous diagnosis/curation;
real-model composition and sequential handoffs on nonlinear tasks; native ternary
training/inference and hardware resource measurements; Aegis Runtime refactor and
separately reviewed NSS adapter; production concurrency/security/authentication;
Core-successor proposals/qualification; optional native HSA/MSA, recurrent depth,
DARP and multimodal generation. Six areas above is NOT a completion estimate for B.

not a trained temporal neural state, learned AR loop or online neural adaptation. The
learned temporal and sparse/local-learning branches remain separately testable research.
