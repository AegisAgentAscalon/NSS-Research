# MegaMind Alpha — v0.4.14 implementation rules

The prior connected local demo remains complete. PersistentState001 now extends scoped
symbolic state using the same Generations owner; read its source map and audit. Next is
independent review, then a SEPARATE trained delayed-cue probe—not live adaptive weights.

- TaskRecord v1 is legacy; v2 scope needs explicit reviewed BIND_STATE on a running stage.
- No unscoped compatibility shim may reach scoped state. Both live and historical managed
  inspection require exact holder/scope. History is not current retrieval/serving authority.
- All S1 deltas require a different declared reviewer, exact proposal digest and short TTL.
  This conservative review rule is not authentication or automatic sensitivity detection.
- Protect scope/policy/source/receipt/Core identities. Never treat persisted prose as root
  instruction. Do not introduce another state database or persistent permission cache.
- EXPIRE/RETIRE is explicit, keeps revision history, and does not imply erasure/unlearning.
- Source/identity disputes block current use; correction does not erase the original.
- Generations remains sole owner of current generations, stage tickets and TaskRecord
  heads. Archive and snapshots keep their own records. Context remains read-only.
- LearningCycles owns plan/approval/dispatch/proposal and exact owner-receipt references.
  The learner has no certificate, generation review, release or private SQL permission.
- CandidateEvidence is a closed installed read-only adapter. It calls owner public APIs
  and rechecks parent certificate through Qualifications, never certifies its own data.
- Preserve disjoint original and CandidateEvidence001 formats. A2 != A. A candidate
  family requires its own CORE/A2/A2B and exact directed returns; parent Core approval
  is additional lineage evidence, not a substitute local-family certificate.
- Qualification rechecks current source/prerequisites before numerical review and again
  before commit. Reviewer must differ from both request producer and actual trainer.
- Release grants remain fresh, exact, expiring and separately scoped. Training or
  NEURAL_PROBE_REPLAY permissions cannot authorize candidate-family publication.
- Historical reads do not renew permissions, republish or repeat external effects.
  Revocation can make a historic candidate unusable while retaining its evidence.
- Return to the exact parent artifacts with a NEW epoch and approval; rollback does
  not rewind the outside world or recreate old stage permissions.
- Fixed numerical controllers do not equal learned evaluator/router weights. Scoring
  criteria and fixtures are developer-visible, not protected independent benchmarks.
- Core-only/frozen checkpoint is not proof of stable personality. Bytes != tokens;
  numerical ternary-Core reference != native packed q1.58 performance.
- Freeze executable source before code-bound numerical testing. Changed implementations
  require fresh evidence. Never weaken an exact verifier to hide a historical mismatch.
- Reuse mechanisms without merging domain ownership. Remove proven stale duplication,
  preserve distinct branch/crash regressions, record additions and deletions honestly.
- Single-worker local roles are attestations, not production identity/authorization,
  concurrent serving or an Aegis Runtime execution permit. No network/private ingestion.
