# Implementation completions fixed before any model call or task draw
Execution v0.2 implements reviewed scientific protocol v0.1. No source/result from a historical learner is used as initialization.

* Evidence format is the inherited durable, per-frame zlib envelope with full-array content aliases verified by bytes, then a lossless whole-envelope delivery codec. Scalar metadata and all branch-specific authority records remain distinct. No QP/protection code is imported by the new runtime.
* The common receipt is published to all four forked learner namespaces. Those namespaces have different recorder sequence positions, but identical observed scope/cue/label/receipt/parameter-version semantics. U/F/R authority equality is checked after removing only the recorder-local receipt_sequence field. Each full field remains captured and independently checked.
* The current public label table is the lawful rehearsal record store. R selects fixed old keys0..7; F selects the latest current focal receipt eight times. Parameter updates never overwrite the evidentiary source version. The batch is a separate recorded operation, not a second receipt consumption.
* Synthetic technical prior receipts use first16 hex SHA256 of `REHEARSE01-v0.1|{wire/fixture:016x}|historical|{cue}|receipt`. They are imported through a declared fixture-only path. Sandbox copied batches use those explicit prior receipts, not an unrecorded extra training update. Non-neural receipt/fault vectors are literals in static_checks.py. No extra model call is hidden in those tests.
* Query-stage keys are `post_real`, `pre_extra`, and `post_extra`. B1/U's post_real trial3 value is reused in the time-aligned recovery comparison without another forward. Frozen N has only ordinary post_real observations. Pre-feedback and reconstructed-fork predictions are separate.
* Trial3 B1/U get checkpoints after their receipt and after trial6; F/R also get a post-batch checkpoint. Main weights/RNG/order cursor checkpoints are0,25,50,75,100. Probe checkpoints0/10. There are1284 expected checkpoint frames per complete pass.
* The independently reconstructed float64 derivative and clip norm must be within the empirical proposal tolerance. Float32 scalar clip factor is separately checked from the recorded norm. Raw product and resulting weights are byte checked. Batch reduction accumulator, mean64, mean32 and applied product are independently byte checked. This is not a proof of a true-gradient numerical error bound.
* The primary worker is closed before the final independent scorer runs, so the completed event-log footer is included in the final audit. Scorers at earlier gates may read an open but fsynced prefix. Final replay starts a fresh process, reinitializes all models/generators and repeats actual work, not merely aliases old predictions.
* Cost admission uses all record kinds actually observed in fixed fixtures/probes, the complete counts in RECORD_KIND_COUNTS.json, and the predeclared1.35live/1.5delivery multipliers with32/18MiB reserves. Both projections remain empirical, not compression proofs. Actual resource caps remain enforced independently.
* Main data have one new balanced map per group/scope under the frozen seeds. The prior-map audit is descriptive; no rejected/resampled mapping for novelty or performance. Old source arrays and raw historical payloads are not loaded as models.
* A scientific failure does not cause retry, extra steps, rejection sampling or gate revision. The user's conditional NBR-01 return plan is in program/USER_RETURN_PLAN.md; no subsequent experiment is dispatched here.
