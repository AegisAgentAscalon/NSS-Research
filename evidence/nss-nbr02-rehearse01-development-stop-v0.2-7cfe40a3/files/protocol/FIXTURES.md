# REHEARSE01 v0.1 — proposed admission fixtures
Not implemented or executed in this review. Their work is included in WORK_LEDGER.json.

## A. Non-neural contract fixtures (no model calls)
Strict receipt ID/scope/version parsing; missing/unregistered cue; already consumed receipt rejected as new
feedback but accepted as declared replay evidence; correct record counts; F duplicate allowed and R duplicate
forbidden; unreleased, revoked, conflicting, wrong-scope and stale labels rejected; no hidden score access;
probe/query immutability; sequential intent/commit and interrupted writer classification.
Use copied records and explicit clean controls. A valid false label with no public inconsistency is recorded
as unidentifiable. No oracle leak may turn it into a successful detector case.

Admission arithmetic tables include H=0, an odd positive H, negative gain, exactly half recovery, an absolute
accuracy failure, insufficient informative fits and a group pass retaining an individual failed fit.
These are synthetic count tables, not rescoring known PROTECT01 outcomes under a new gate.

## B. Derivative and reducer fixtures
Use four historical 674-parameter geometries crossed with G/L:8 single-example derivative evaluations,
no application. All W/U/b/V/a zero except U[0,0]=U[1,1]=.5,V[1,1]=1.
Coupled cases additionally U[1,0]=.5; nonzero-activation cases additionally W[0,22]=.4.
Prefix[22,20,0], target0. Diagonal raw G/L equality and coupled own-formula fidelity must pass. The
coupled-zero diagnostic retains its known nonzero discrepancy, not a requirement for dense G/L agreement.
No old-margin/QP derivative diagnostics are part of this study.

Pure674-vector reducer cases are embedded in the first two coordinates; others zero:
1. Eight copies of (1/8,-1/4): mean identical.
2. Four(2,0), four(-2,0): zero mean, no hidden selected nonzero update.
3. Four(2,0), four(0,1): mean(1,1/2); clipping the mean differs from mean of individually clipped vectors.
4. Exact signed/subnormal float32 components with ordered float64 accumulation and reference cast.
5. Deliberately replaced mean, clipping factor or applied displacement: reject against clean copy.
6. Nonfinite gradient/shape/order/prestate mismatch: reject before scientific commit.
Input tables and byte conversions must be finalized in the future execution source lock. No random
network fixture is selected because its result is favorable. Model-dependent batch fidelity is additionally
checked for every real F/R operation and sandbox batch, so pure-vector tests cannot substitute for it.

## C. Twelve clean branch contexts
Technical old labels[0,1,0,1,1,0,1,0]; technical focal8 has initial0 and10 has initial1.
case0=(f8,p4); case1=(f10,p0), with normal six-receipt reversal grammar.
Use an untrained paired fixture initialization from init/fixture. Import eight explicitly synthetic public old
observation records through the normal authority checker; do not claim the untrained model knows them.
Cross two cases ×two methods ×delays0,8,32 =>12 contexts,240 applications per pass.
Each includes four complete branches, the two extra batches, N, and full inventories. Low task accuracy
is expected and does not fail an engineering fixture. Every method's matched delayed branch must reproduce
its own d0 gradients/updates and outputs; live detached filler states and measured time can differ.

Generate32 filler coordinates from each case/trial-specific seed. Alternate other/same scope, choosing
uniformly among that scope's four old cues; d8 takes the first8 of d32. Branch reconstruction recreates
the original three-event cue graph, not another waiting period. No fillers inside the eight replay examples.
Across the12 contexts, delay adds3360 cell examples and no heads per pass.

## D. Eight isolated deliberately faulty batch applications
For G/L ×target0/1 ×wrong-sign/double-step, use a fixed untrained fixture model and the corresponding
synthetic released evidence (cue0 for0, cue4 for1). Construct eight-copy batches under that method and
compute the correct mean and clipped step. Apply exactly ONE intentionally wrong signed or doubled
final displacement; query once afterward. Record expected injection separately and prove the clean
application checker rejects it. These weights never initialize learning or normal fixture branches.
8applications,64 derivative-example prefixes and8 scratch queries per pass. Require nonzero expected step
or stop as an inadequate detector fixture; do not silently choose another random model.

Wrong per-example clipping or mean computation can be tested on copied recorded gradients without
extra parameter applications. A serial-SGD alternative is not secretly run under this eight-application budget.

## E. Probe and schema admission
Independent probe init; same technical labels. For each method ten old warmup updates, old8 inventory,
then both technical case contexts from the same step10 checkpoint, with corresponding frozen N:
2×(10+2×20)=100 applications. Initial labels cover both scopes before replay. Preserve checkpoints at0/10.
Probe results cannot choose the learning rate, criterion, candidate mix, seeds or training duration.
Forecast all new batch-example and batch-apply evidence; an ordinary single-update probe alone is insufficient.
