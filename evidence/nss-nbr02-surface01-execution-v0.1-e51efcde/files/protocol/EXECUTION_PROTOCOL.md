# NSS NBR02 SURFACE01 — Execution v0.1

## Authority and scope
The user's instruction “Oh yeah, always try to make it so the failures are as informative as possible. Run it.” dispatches the immediately preceding SURFACE01 Proposal v0.1. This document freezes its previously open implementation items before any main fit. It does not dispatch follow-up studies or adopt a successor architecture. Original proposal preserved unmodified. No historical models loaded; no model downloads.

## Unchanged scientific recipe
GRUCell(26,64) + Linear(64,9), 18,249 total scalar parameters; eight-item SET/CLEAR/RESET/NOOP checklist; eight B cues with original parity labels; separate zero-initialized B state. Four seeds 4101–4104, 2,000 parent updates each, batch of 32 A streams x 32 events plus all eight B cues, loss 0.5 A mean CE + 0.5 B mean CE. Adam 0.003, betas (0.9,0.999), eps 1e-8, no weight decay, foreach=False, fused=False; global active-gradient clipping 1.0. Four independent correction contexts 0,3,4,7; two B paths per context, 64 steps each, stages 0,1,2,4,8,16,32,64. No A rehearsal. Only final parent and final correction stage enter gates. Thresholds unchanged from proposal.

## Fixed generator: TARGET_MASK_ROUNDS_V1
Event IDs: SET 0–7; CLEAR 8–15; RESET 16; NOOP 17; B cues 18–25. Every A stream starts empty. Repeated rounds sample a desired next-action class k uniformly from 0..8. Bits below k are one, bit k is zero unless k=8, and bits above k are independent Bernoulli(0.5). The generator applies every differing SET/CLEAR event in shuffled order, then a random dwell. Dwell events are 50% NOOP, 50% randomly indexed idempotent SET/CLEAR. Targets and masks are generator state and scoring evidence only, never model inputs. Stream is cut at its specified length, including intermediate edit states.

Families: mixed uses uniform target classes and dwell uniform 1..4; idempotent uses the same masks and dwell 5..9; revision alternates full mask and uniform target class 0..7, dwell 1..4; reset uses ordinary rounds plus RESET at rounds 0,3,6,... . Each training batch has exactly eight streams per family, randomly permuted. No tuning of this generator after observing any model score. Coverage counts are diagnostics, not a weight-selection device.

Training RNG: NumPy default_rng/PCG64 with seed 100000+parent seed. Complete tokens, labels, masks, family IDs and initial/final RNG records are retained. Torch seed equals parent seed; use documented module default initialization, cell then head. CPU float32, deterministic algorithms, one intra/inter-op thread, MKLDNN disabled, NumPy/BLAS one thread. Actual installed versions pinned in environment.json.

## Admission and confirmation
Admission RNG 200000+parent seed; 64 histories per family (256 per parent), half interrupted at 8 and half at 24, then 32 continuation events. Confirmation RNG 300000+parent seed; eight histories per family (32 per parent), same balanced interruption points, then 128 continuation events. Confirmation is NOT generated or opened until all final parents pass baseline and numerical gates.

Reject exact duplicate panel histories and any exact 32-token window matching a training stream; rejection uses events only, never model scores. Log draw rejections. All 256 checklist states may overlap training by design; new histories are not new state-space semantics.

Training all four fixed parents precedes cohort admission. Any baseline failure stops B adaptation for the entire cohort. It does not drop a seed or trigger retraining. Admission gates apply to suffix events 1..32, boundary separately reported: at least 99% event accuracy, 95% whole continuations, zero false DONE per family; all eight B labels correct and probabilities >=0.8. At 64 histories/family, 95% requires at least 61/64 whole continuations. Main confirmation has eight/family, so 95% requires 8/8. A main joint pass also requires the parent to satisfy its same confirmation competence screen; failed parent histories remain present.

## Numerical and bookkeeping contracts
Canonical torch GRUCell vs independently written NumPy float32 GRU equations, fully free-running from identical initial state over complete checked history. NumPy uses explicit sigmoid/tanh and (1-z)*n+z*h; it does not reseed from the torch hidden state after each step. Every hidden coordinate and logit must obey abs(diff)<=2e-6+2e-5*abs(reference), and argmax decisions must agree. No tolerance changes. Numerical failure blocks qualification independently of competence failure. Full float32 comparator diagnostics retained; no post-result precision substitution.

Canonical evaluation batches group histories by interruption length (admission group size 128; confirmation group size 16). Main continuation uses the same groups. Exact immutable parameter/state hashes, original/copied readout non-aliasing, exact checkpoint round trips, input/history/task/version binding, and original head preservation checked. F-COPIED must equal original A logits exactly; this is an invariant, not a learned success. Shared/copied B graphs have identical gradients in a probe. A predictions never feed back into inputs.

Fault tests: all eight proposal injections and corresponding clean controls. Independent checklist oracles enumerate 256 masks x 18 commands. A paired-history sanity fixture shows identical last NOOPs with different correct answers. Fault receipts expose injected versus observed failures separately.

## Probe, replay and budget accounting
Exactly 48 engineering optimizer applications: one parent-style and F/U adaptation-style probe on seed 4199, each eight prefix updates + four uninterrupted updates + four repeated updates after checkpoint restore in a fresh process = 16 applications, 12 unique update positions. No probe model enters main. Two additional backward passes compare identical B graphs without applying updates. Main 8,000 parent + at most 2,048 B applications. Maximum 10,096 including repeated probe updates. Actual applications logged; no retries, replacement fits, added repair or translator.

Fresh-process inference replay of all final-parent admission logits/hidden states/labels is mandatory, including failures, with zero optimizer updates. Resume probes compare exact model/optimizer/RNG values. Internal reproducibility is not third-party replication. If main adaptation runs, retained checkpoints and exact fixtures also support its replay; delivery must distinguish replay actually completed from mere availability.

Process RSS cap 2 GiB; delivered-evidence cap 512 MiB; reserve 32 MiB for failure records. Main runtime cap 1,800 seconds, reserve 120 seconds before stop. Cost probe provides measured forecast; no fake evidence padding. Resource figures include framework/process overhead where measured, not merely parameters; energy is not instrumented and must be unavailable. Source/environment/protocol and preflight hashes are locked before main. Preflight outcome, including any failures, is retained.

## Saved artifacts and failure diagnosis
Parent snapshots 0,250,500,1000,1500,2000, with optimizer/RNG and data cursor. Adaptation snapshots share unique weights between shared/copied views. Stage 0 references unchanged parent bytes plus a declared fresh empty optimizer, avoiding duplicate parent arrays. Per-event logits/targets, B output probabilities every step, loss, preclip norm, clip scale and actual delta for every parameter tensor are retained. On baseline failure only: final parent is additionally scored on 160 actual training streams from batches 1,500,1000,1500,2000. This predeclared inference-only diagnostic distinguishes residual sampled familiar-task fitting from longer-history failure; it is not representative population evidence. Retain full diagnostic hidden/logit trajectories and first failing admission history per seed/family in its original context. No new fitting or confirmation access. Main failures retain all logits and first representative full hidden-state reproducer per seed/path/mode/head/family, with coordinates and input/weight references; no claim that all class errors share one proven cause.

## Interpretation
Baseline failure is NOT evidence of correction-induced forgetting. Numerical failure is NOT an architecture verdict. F-COPIED retention is mechanical isolation. Readout and transition effects are conditional on this recipe and observed successful B learning. Four independent parents; nested histories, updates and correction contexts are not independent replications. No outcome qualifies new procedural learning, lifelong learning, low-bit learning state, a deployed companion or any core count.
