# NBR-01 status after Qualification010

**Decision:** the declared numerical owned-memory/state-depth reference is qualified; the broader companion/identity problem is not solved. No automatic project-stage transition or deployment has occurred.

## What changed

The comparison no longer depends on an underprepared attention baseline. A task-adapted eight-block untied attention/pointer reader passed direct visible-fact competence and the assisted nominal behavioral screen in all five main pairs. The inherited 818-parameter shared reader and its ordinary continuation also passed. Exact traversal remains a strong, cheaper control on the same owned records.

All evaluation-time parameters stayed fixed. Retained state preserved relationships; enough internal stages combined them. The measured 16-record, sigma .02, cadence 8/32 task has explicit state and CPU costs. This is a bounded hybrid record/depth result, not proof that an unrestricted conventional Transformer is inferior or that native recurrent architecture is the only viable route.

The close-identity continuation failed the full nominal screen in all five pairs. Its raw close-source recall gain came with worse missing-information handling. Keep those checkpoints and failures; do not substitute the new recipe for a working reference merely because a single score improved.

## The reference to freeze

Keep scoped exact ownership/presence and active-registry metadata, declared numerical contents/readability, compatible internal key/value maintenance, query uncertainty policy, and the inherited shared reader. Keep the ordinary continuation as another qualified candidate, and retain the attention and exact controls. Prefer cadence 8 as the reference: cadence 32 passed the headline answer tests but damaged two unqueried relation maps out of 640 in the eight-link horizon condition.

The identity catalogue is protected information about symbols. It is not a source of true relationships. Qualified registration/write decisions remain supplied in the synthetic task. Earlier learned existence maps and every previous repair network are not all incorporated into this combined reference.

## Recommended next decision

Accept the bounded reference as the completed state/depth comparison for this stage, rather than requiring it to solve all semantic identity recognition before any later research can begin. Preserve wider recognition, richer task and less-structured Transformer comparisons as explicit open applicability questions—not silently discarded failures.

Before starting any learning experiment, fix the accepted reference configuration and its regression pack, and make the new learning variable explicit. Evaluation-time weight adaptation would be a new condition. A later learning result must not be attributed to better memory bookkeeping or a changed reader without a controlled comparison.

User-side independent execution and later longitudinal evaluation remain essential before making product claims. The packaged checks are internal reproducibility, not external replication. No additional experiment is launched by this status review.
