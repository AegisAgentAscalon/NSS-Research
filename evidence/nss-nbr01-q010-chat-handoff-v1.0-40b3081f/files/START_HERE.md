## Scientific question and full scope

Q010 asks how inherited state/depth reading compares with ordinary continuation, close-identity continuation, and a task-adapted attention reader on owned symbolic records, including missing/UNKNOWN behavior. The intended comparison has **three newly fitted arms across paired seeds 1201–1205**, 6,000 updates per fit, for **15 new final checkpoints** and 90,000 total main updates. Five exact inherited RecordHop readers (801–805), cap-only controls using the same weights, and an exact-owner privileged control remain in the comparison. The declared evaluation includes all **64 condition cells** and six readers per seed: direct and assisted chains, supported and missing classes, close identity, durability, lifecycle, corruption, maintenance and ablation cases. The corrected **analytical planned workload**, not observed execution, is 449,640 query chains and 3,045,480 reader-stage calls. Independent verifier retraining is a separate three-fit, 18,000-update workload; it does not replace any main fit.

The proposed core assisted accuracy screen is 0.90, direct visible-fact screen 0.95, and nominal cadence08 durability screen 0.90 **per support class at each of 17 checkpoints**. Other durability variants are report-only.
