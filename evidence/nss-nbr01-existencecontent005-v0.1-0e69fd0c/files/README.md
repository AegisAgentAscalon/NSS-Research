## Checks

From the extracted directory, with the listed dependencies already installed:

```text
python run.py checks
```

`RUN_RESEARCH_CHECKS.cmd` invokes the same path. The Windows launcher and Windows
execution are **NOT_RUN** here. Checks verify the manifest, run 44 unit tests,
and rescore saved answers/status from the source event rules. They do not
retrain, install packages or make network requests. Temporary check receipts
are written to the OS temporary directory, not this release.

For a full fresh evaluation replay, choose a **new** external directory:


This re-executes 45 configurations and compares all saved arrays, rows and
status estimates. It is longer than the ordinary checks. Existing result
folders are never overwritten. Full replay was performed in a fresh interpreter
before delivery; see the verification receipt for exact scope.

## State compatibility

The research state schema is `existence-content005/state-v1`. Explicit existence
uses +1 for present and -1 for absent; a sign/mean readout is a declared encoding
contract. A new write sets content and status in the same synchronous operation.
Snapshots bind scope, mode, dimensions and both source/model identities. Older
16-D states cannot be silently interpreted as this 17/20-D format. Migration
from older states was **NOT_RUN**; rebuilding from eligible exact events is an
available proposed route, not an implemented cross-version migration guarantee.

`read_status()` distinguishes empty, present/readable, and present/unreadable.
Status is not factual truth, permission or confidence. A stable but wrong value
can remain stable. The neural existence coordinates are also corruptible.

This package preserves the frozen Primary / task-learning Secondary / reflective
Tertiary / advisory Validator role design, S/T alternation, exact evidence and
no-overlay direction. No new major core or production deployment is introduced.
