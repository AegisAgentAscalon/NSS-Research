Created before pilot fits. Standalone NBR-01, not NBR-02 or integrated cores.
Task: 16 freshly coded identities per generated containment graph; two explicit
room/self records; one functional relation per source. Query asks terminal room
or UNKNOWN when a required relation was not established. Model inputs have no
integer path, answer or oracle-selected next record. Encodings, room semantics,
write authorization, intermediate training targets, finite memory allocation and
presence convention are supplied scaffolding, not discovered cognition.

Candidate review: visible-facts learning first with RecordHop, gated read/GRU,
tied cross-attention, unshared four-block attention and flat snapshot-GRU.

stream-history GRU. A separate learned matcher will bind streamed writes into
bounded record state; all readers then get the same snapshot for isolation.
