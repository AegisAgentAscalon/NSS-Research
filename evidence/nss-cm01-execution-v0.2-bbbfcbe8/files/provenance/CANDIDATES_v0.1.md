### Preserve the inherited study rather than overwriting it

Q010-P1 retains its 768 L1/D1 cases, three development and five evaluation catalogue families, 11,520 reader chains/stages, cached gate decisions and 768 privileged exact-owner decisions. Its one threshold per role, primary near arm, development-only calibration and two-hour / 4 GiB limits are unchanged. If a stratum is nonidentifiable, stop gate optimization there. No result for this follow-up is claimed here. [S1:9–15; S3:3]

### Proposed sequence

First freeze the role-change decision and inspect the old-interface information limit. Next freeze and authorize CM-01 as a separate contract. Only a useful, correctly attributed result should motivate continuity, update-cadence or recovery work. The full Q010-P1 threshold sweep need not be a prerequisite to a publicly documented information-enriched experiment, but the information audit cannot be skipped.

Passing CM-01 would support a particular hybrid retrieval/management mechanism. It would not prove that token syntax is special, that recurrent cognition improved, or that tiny context can sustain a day-long task. Those questions require the later controls.

## CM-01: grounded-reference pilot
*PROPOSED FIXED-WEIGHT STUDY  |  EPISODES AND VISIBLE EVIDENCE*

Hypothesis: retaining a small amount of legitimate reference information can improve query-to-record selection. The alternative is that gains come entirely from exact lookup or added information, rather than token representation or learned reading. Both are informative outcomes. The near reader is the primary arm; ordinary and attention remain declared comparisons.

### Evidence contract

Build a public, append-only registration/selection journal from observable events. Independently allocate opaque handles; do not derive them from answer IDs. A management layer may retain scope, handle, revision and binding-event references, and resolve only records exposed by that journal. It must not access protected owner arrays, hidden source identity, query kind, anchor labels or the scoring ledger. Keep the original output resolver unchanged and disclose its existing catalogue assistance.

Before scoring, demonstrate isolation: changing protected metadata while holding visible history and input fixed must not change the management output. Reusing identical visible inputs under opposite hidden labels illustrates the original information limit. Valid-but-wrong references without observable contradictory evidence remain an explicitly nonidentifiable stratum, not a validator failure.

### Proposed size: 512 episode records

Use eight independent catalogue/episode families: three development, five held out. Each family contains eight strata with eight records per stratum: 64 records/family, 512 total. Within applicable noisy strata, allocate four records to each sigma, 0.01 and 0.2. Repeated public inputs in counterfactual pairs remain separate labeled records.

| Stratum | Purpose |
| --- | --- |
| 1. Bound known | Current, relevant reference; ordinary known-query control. |
| 2. Bound close identity | Current relevant reference amid a near-identity decoy. |
| 3–4. Unbound known / absent | Matched-noise opposite-truth pairs; information-limit control. |
| 5. Stale revision | Reference survives a revision or deletion event. |
| 6. Cross-scope reference | Locally valid handle from an unrelated namespace. |
| 7. Wrong reference | Four observable binding mismatches and four no-cue cases per family. |
| 8. Correction / conflict | An explicit correction or unresolved competing binding. |

## CM-01: representation and intervention
*SAME-INFORMATION CONTROLS  |  FROZEN ADAPTER*

| Interface | Operation |
| --- | --- |
| A. No retained workspace | Unchanged numerical query/read path. This is an information ablation, not an equal-information claim. |
| B. Structured workspace | Validated fields from the observed event history guide a fixed public-reference resolver. |
| C. Serialized workspace | Exactly the same fields and policy as B, expressed as a compact control string. B and C must agree bit-for-bit. |

CM-01 does not teach the Q010 models to read strings. A deterministic external adapter interprets B/C and either preserves Q, substitutes the canonical key from a legitimately observed record, or emits a distinct management-abstention action. It never changes K/V/valid, model weights, the original learned decision rule or the original cleanup resolver. Every substitution logs both queries and its public provenance.

### Concrete experimental serialization

```text
01|00000003|0000000000000011|00000004|000000000000005b|R
```

Fields are version, 32-bit scope, 64-bit handle, 32-bit revision, 64-bit binding event and operation. Use strict lowercase hexadecimal widths and a fixed ASCII grammar. For this wrapper pilot only, define UTF8_BYTE_V1: one byte is one control symbol, with a cap of 64 symbols. This is not a natural-language tokenizer or a native token embedding experiment. Count the actual string bytes, parsed fields and resolver storage.

Unknown, absent and invalid fields have explicit reserved encodings; parsers must reject malformed widths or unrecognized operations. The sample is a format example, not an observed result. Native 8/32/64-token budgets belong to CM-05, where a real tokenizer and embedding cost must be pinned.

### Two non-neural controls

Add a public-journal-only exact lookup using the same observable records, and a separately labeled privileged exact-owner oracle. The former tests how much the wrapper/archive already solves without a learned reader. The latter remains diagnostic and may consult protected truth. Their information access and outcomes must never be pooled.

Limit B/C to two logged public-directory/archive lookups per request. A missing or ambiguous reference falls back to the unchanged public query; an observably invalid proposed binding emits management abstention. Validity alone is insufficient to claim relevance. Freeze this routing table before evaluation.

## CM-01: counts, decisions and stopping
*EXPLORATORY CRITERIA  |  NOT Q010 ACCEPTANCE THRESHOLDS*

| Work item | Declared maximum |
| --- | --- |
| Main public-query variants | 512 records × 15 readers × at most 2 distinct Q variants = 15,360 forwards/stages. |
| Main scored interfaces | 512 × 15 × 3 = 23,040 decision rows; B/C reuse cached outputs. |
| Main non-neural controls | 512 public exact-lookup + 512 privileged oracle = 1,024 decisions. |
| Integration fixture | 8 separate records × 3 roles at seed 1201 × 2 variants = 48 forwards; 72 interface decisions + 16 controls. |
| Exact replay | Replays the above neural work, at most 15,408 additional forwards. Total producer plus replay cap: 30,816. |

### What is scored

Keep expected record/content truth separate from expected management action. Report supported recall, UNKNOWN specificity, false binding, reference-validation errors, abstention, coverage, revision correctness and lookup costs by model seed, family and stratum. An abstention on a known query is a recall loss even when it is a sensible management response. Do not count rejection of every query as successful recall.

### Proposed exploratory decision rules

First require B/C exact equivalence and zero protected-data leakage in the specified fixtures. For the near arm, a useful retained-reference result requires at least a 10-percentage-point gain over A on bound close-identity recall in at least four of five held-out families, averaging the five fixed model seeds within each family. Bound ordinary-known recall may lose at most one point in those same families.

Report the complete family grid. On observably invalid-binding strata, false acceptance should be at most 5% in each held-out family. No-cue wrong references and matched unbound opposite-truth pairs are report-only information limits. If the recall gain is absent, record a null result; if the public exact lookup matches the hybrid, attribute the result to the management/archive mechanism, not newly demonstrated neural recognition.

All values above are new proposals, fixed before results. No gate tuning or held-out selection is allowed. Use newly allocated CM-01 seed domains and freeze their derivation after checking for conflicts; do not assume a new namespace alone proves disjointness. Model seeds 1201–1205 are intentionally reused.

Proposed cap: two hours from study preparation through scoring and replay; 4 GiB process-tree RSS. Stop on a cap, interface/source mismatch, leakage or parser-equivalence failure. Retain partial outputs and failed fixtures. Additional variants require a new protocol version.

## CM-02 and CM-03: continuity and refresh
*CONDITIONAL HARNESSES  |  SEPARATE FROM NATIVE LEARNING*

### CM-02 — Is the workspace useful after intervening events?

Extend the declared store/event harness, not the Q010 training pipeline. Compare state with no explicit workspace, state plus grounded workspace, the same information in structured fields, and workspace plus public exact retrieval with the recurrent/task state disabled. All observe the same events and have the same permitted archive API. A channel ablation intentionally changes retained information; report that rather than calling all arms information-identical.

Include delays of 0, 32, 128 and 512 intervening events; unrelated task switches; corrections; and interruption/resume. Exact targets and a simple task-state transition specification must be locked before dispatch. The first tier can test task/record continuity in a synthetic harness; it cannot demonstrate general recurrent thought or language competence.

Proposed bound: eight fresh families × four horizons × four stress types × four episodes = 512 episodes per system arm. One fixed readout at the declared endpoint, three primary-system variants plus the same-information encoding check, and the five saved model seeds for the predeclared near role. Adding all 15 readers is a separately costed extension. Log event updates as well as neural calls; freeze the precise call ledger before running.

Evidence to advance: lower context burden at comparable task success, or a clear continuity improvement at matched total active-memory budget. At minimum, publish the zero-workspace and state-disabled ablations. If removing recurrent/task state changes nothing, the result supports workspace/archive continuity, not a necessary recurrent contribution.

### CM-03 — Refresh cadence and evidence checks

Use one frozen CM-02 configuration. Compare never-refresh after initialization, refresh every event, refresh every 8 events, refresh every 32 events, and the declared event-triggered policy. Separately compare evidence-linked validation with no such check; do not introduce a new model or training objective in this experiment.

Proposed bound: five schedules × two check policies × eight fresh families × 16 episodes = 1,280 episodes per fixed reader seed. Reuse matched event streams across policies, not held-out CM-02 families for calibration. Choose any adjustable trigger rules on development only.

Proposed advance criterion: at least 30% fewer workspace refreshes than every-event refresh with task accuracy within one percentage point, and no increase greater than one point in wrong binding. Report actual bytes/tokens rewritten, lookup traffic and latency; fewer refreshes alone need not mean lower total cost. These small-family comparisons are exploratory.

## CM-04 and CM-05: robustness and native state
*CONDITIONAL FOLLOW-UPS  |  SEPARATE AUTHORIZATION FOR NEW TRAINING*

### CM-04 — Resume without inventing missing state

Cross four recovery conditions—intact, recurrent/task-state reset, missing workspace, and jointly reset state plus missing workspace—with four reference/evidence conditions—valid, stale, valid-but-wrong, and corrupted or unavailable payload. Proposed bound: eight fresh families × 16 cells × four episodes = 512 episodes per declared system arm. Freeze precise corruption magnitude, timing and gold expectations before running.

Measure task resumption, time and retrieval cost to recover, wrong-binding rate, retained constraints and evidence fidelity. Preserve cases where recovery is impossible. Exact archive availability does not imply the system can reconstruct a missing latent state, and a correct pointer cannot repair an erased value or establish the truth of an unverified wrong-but-valid payload. [S2:20–24]

Use separate judgments for record binding, payload availability and payload correctness. A semantically plausible answer from damaged evidence remains a failure when it contradicts the independently preserved truth. Do not silently restore the answer ledger into the archive. Evidence repairs must come from an explicitly permitted independent source and have their own cost.

### CM-05 — Native recurrent state plus a small token lane

This is the actual learned-architecture branch. It requires a separately authorized, small new model/interface family; the 15 Q010 main exports remain untouched. Compare recurrent-only, token-workspace-only plus retrieval, recurrent plus 8/32/64 discrete tokens, an information-matched structured interface, and recurrent plus soft latent slots. A growing-context baseline is useful as a cost reference, not an unlimited free resource.

First make an information-matched comparison with identical evidence and resolver permissions. Then make an iso-budget comparison using total state bytes, compute and traffic. These are different analyses: extra slots cannot be credited as superior organization merely because they add memory. Pin tokenizer, vocabulary, embedding widths, recurrent-state dimensions and maximum retrieved context before fitting.

The controller must create and update its own workspace from observable events. Teacher-provided or gold references may appear only as labeled upper-bound controls. Compare a frozen deterministic manager with a learned one. Train new arms from declared initial states on disjoint episodes, using paired seeds and retained optimizer/RNG checkpoints; no exact training continuation of missing Q010 histories is claimed.

Status: research candidate only. Parameter counts, data volume, optimizer, number of updates and training caps are deliberately not authorized here. A separate versioned training protocol must define them before launch. Begin with discrete context; soft slots are a distinct capacity/representation test, not “free non-language tokens.”

## Common accounting and reproducibility
*GUARDRAILS FOR EVERY CANDIDATE*

### Measure the system, not just its visible token count

| Category | Required accounting |
| --- | --- |
| Active memory | Recurrent/task state, token IDs, embeddings, KV caches, parsed fields, resident retrieval results and controller buffers. |
| Persistent memory | Payloads, event journal, reference directory, dictionaries, index overhead and checkpoints. Report logical and physical bytes. |
| Traffic and compute | Cumulative token/symbol processing, workspace rewrites, retrieval bytes, read/write count, forward/stage count, replay, wall time and peak process-tree RSS. |
| Behavior | Answer accuracy, known recall, UNKNOWN specificity, coverage, calibration if measured, false binding, constraint retention and recovery success. |

A 64-symbol wrapper is not a 64-token language model. Soft slots are dense arrays and must include dimension and dtype; subsequent caches also count. If persistent archive growth is unbounded, report that separately from bounded active context. A throughput or capability-per-token ratio alone can hide a large external controller or archive.

### Evidence chain

Lock source, configuration, seeds, codec/tokenizer, interfaces, event schema and scoring rules before held-out generation. Keep entire catalogue/episode families together. Hash exports before and after each run. Save visible inputs, journal events, workspace transitions, lookup receipts, raw numeric outputs and every predicted/expected pair. The independent scorer must derive truth from an isolated source ledger, not producer success flags.

Replay from a fresh process and distinguish replay executions from independent observations. For reused Q010 arithmetic, retain the frozen and amended underflow verifiers and their documented rejection cases. Do not fit a tolerance to new failures. Record exact dependencies and backend; a CPU replay is not a portability proof.

### Small, complete handoffs

Deliver the new protocol, source, manifests, receipts, results and raw evidence of the bounded new study, not another copy of every historical ZIP. Depend on the existing 48.7 MB recovery archive by hash. If raw outputs exceed a practical per-file budget, retain the entire lossless evidence set in numbered parts with a manifest; never drop failed cases to meet a size target.

This planning package contains no trained weights or numerical study results. Its integrity verifier checks its own generated files. It does not verify the full compact baseline, prove a new hypothesis or recreate omitted historical evidence.
