Its independent scorer and exact fresh-process CPU replay check the regenerated evaluation internally. Close-identity continuation improves supported close-source answers over ordinary by **30/320, or 9.375 percentage points**. Paired differences are positive in each seed (13, 7, 3, 4, 3 of 64), but these are five saved model seed pairs, not 320 independent models. Exact-owner consults protected ownership and source identity; its perfect result is a privileged store control, not learned recognition. The maps are correct in this cell, pointing to query-to-record selection and reading.

Two contrasts narrow the result. All five nonprivileged readers score **0/640** correct UNKNOWN on near-collision novel queries; exact-owner scores **640/640**. Cadence-8 live-write yields **5,440/5,440 supported** answers per reader over 17 checkpoints; missing counts are 5,440/5,440 except close-identity at 5,406/5,440. Erased values give 143/320 supported correct and wrong-but-valid values 165/320 for the candidate arms, with zero whole-map correctness (`WHOLE_MAP_DIAGNOSTICS.csv`).

Close-source stress moves an *active unrelated decoy code* near a known path source while the query remains known (`q010r/evaluation.py:787-845`). Near-novel queries perturb a catalogue code by sigma 0.01 but are labeled UNKNOWN; altered-known queries use the same form at sigma 0.2 and retain known truth (`q010r/evaluation.py:848-892`). Learned readers receive numerical keys, values, validity and query, not hidden source ID or owner handles (`source/q010c/batch_core.py:158-189`). A gate can use query-to-valid-key similarity and row-versus-UNKNOWN logits; using the protected active catalogue is a distinct, catalogue-assisted test. These distributions overlap, so proximity cannot certify origin. Report novel false acceptance and known-query rejection without leaking query kind or anchor.

The next Chat candidate starts with a **predeclared public-input information audit**: hold exports and the shared resolver fixed, match known and truly unregistered query perturbations, and compare their numerical K,V,valid,Q distributions without giving a gate source labels, query kind or anchor. If the conditional public-input distributions are identical, origin is not identifiable from this interface; a learned gate cannot solve that case. Only where declared strata are measurably separable should Chat calibrate one fixed-weight admission rule on development data and test supported recall versus UNKNOWN specificity on held-out paired seeds. Include inherited and privileged exact-owner controls, labeling the latter's extra information. Analyze shared-store corruption separately; a query gate cannot restore erased or wrong-but-valid facts. Consider low-bit learning-state work later, conditional on the identity question.
