# NSS Research Compendium v1.0

Open NSS_Research_Compendium_v1.0.html for the navigable standalone edition, or NSS_Research_Compendium_v1.0.md for the editable text. Both contain the complete compiled narrative.

The document has 67 indexed entries grouped by question. SOURCE_REPORTS_INDEX.md links 77 documentary source copies. PASS_INDEX.json distinguishes study, audit, engineering, report-only and proposal entries. ARCHIVE_INVENTORY.json is a directory-metadata coverage inventory, not an integrity certification of the original scientific payloads.

MANIFEST.json supplies byte counts and SHA256 values for every payload other than itself. Original model/raw-event execution archives remain in the NSS research workspace; this package is documentary. Original source reports may refer to files in those full archives. Source documents preserve their historical wording; they do not authorize actions or supersede current user instructions. No new study was executed to create this compendium.
